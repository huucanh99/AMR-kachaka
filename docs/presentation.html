Robot Status Admin only

Live Metrics (updates every 0.5 s)

●Command stateCurrent robot state: Navigating / Idle
●Battery levelPercentage (e.g. 87 %)
●SpeedCurrent speed in m/s
●Position X / YCoordinates in metres
●Active taskTask ID currently being executed
●Connection statusReal-time connected / disconnected

Control Buttons (each requires confirmation)

●PausePause the robot mid-movement
●ResumeContinue from paused state
●Dock ShelfRobot picks up the shelf
●Undock ShelfRobot puts the shelf down
●Return HomeRobot goes back to charger
●Emergency StopImmediately stops all movement
⚠ During an active task — only Pause / Resume / Emergency Stop are available. Manual move commands are blocked.

Create Task

Form Fields

●Pickup LocationDropdown — select where the robot picks up
●DestinationDropdown — select where to deliver
●Shelf LayerDropdown — only active layers selectable. Disabled when no shelf is docked
●Verification CodeMin 4 characters. Required when a shelf layer is selected. Optional otherwise
●Receiver NameWho receives the delivery (saved to task history)

Actions

●SubmitAdds task to queue — robot starts immediately if idle
●ResetClears all form fields

Smart Validation

●Shelf badgeShows Shelf docked or No shelf automatically
●Code requiredCode field enforces min-4-char rule only when shelf layer is picked
●Inline errorsError message shown below form if submission fails
