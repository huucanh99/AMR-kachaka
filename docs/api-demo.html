📊 Robot Status
Get the robot's current position, battery level, and command state all in one call.
GET Full Status /robot/status
Returns pose, battery percentage, and what command the robot is currently running.
GET Ready Check /robot/ready
Quick check — is the robot online and ready to accept commands?
GET Current Pose /robot/pose
Returns the robot's X/Y position and heading angle on the map.
🔋 Battery
Check the robot's battery percentage and charging status.
GET Battery Info /robot/battery
Returns percentage and power supply status (charging / discharging).
📍 Locations
Get all named locations registered on the robot's map. Use these IDs to send move commands.
GET All Locations /robot/locations
Returns a list of locations with their IDs and names.
🗂️ Shelves
Get all shelves the robot knows about, and check which shelf it is currently carrying.
GET All Shelves /robot/shelves
Returns a list of shelves with their IDs and names.
GET Moving Shelf /robot/moving-shelf
Returns the shelf the robot is currently carrying, or null if none.
🗺️ Map
Get the robot's current map as a PNG image and list all available maps.
GET List Maps /robot/maps
Returns all available maps and the ID of the currently active map.
GET Map PNG /robot/maps/png
Returns the current map as a base64 PNG image with width, height, and resolution.
🚗 Move to Location
Send the robot to a named location. Get location IDs from the Locations endpoint first.
POST Move /robot/move
Robot starts moving to the specified location immediately.
📷 Camera
Live MJPEG video stream from the robot's cameras. Streams directly into an <img> tag in any browser — no extra libraries needed.
Select Camera
Side options: front · back · tof (depth sensor)
Live Preview
Requires robot to be online. Click a camera button above first.
Select a camera to preview
🎮 Controls
Control the robot's movement — pause, resume, return home, or emergency stop.
⚠️ Emergency Stop halts the robot immediately.
