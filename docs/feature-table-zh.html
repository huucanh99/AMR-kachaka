AMR Kachaka 管理平台 — 網頁功能總覽

各頁面介面說明 · 2026年5月

# 頁面名稱 存取權限 功能說明
帳號與認證
1
登入
/login
 所有人
  • 輸入帳號密碼登入系統
  • 登入成功後自動跳轉至首頁
  • 登入失敗顯示錯誤訊息
  • 提供前往「註冊」頁面的連結
  • JWT Token 存於瀏覽器，逾期自動登出
2
註冊
/register
 所有人
  • 填寫帳號與密碼建立新帳戶
  • 帳號重複時顯示錯誤提示
  • 新帳戶預設為一般使用者（非管理員）
主要功能頁面
3
首頁 / 儀表板
/
 一般使用者
  • 平面地圖：顯示所有已登記地點，機器人目前位置以藍色燈號標示（移動中閃爍、到達時常亮）
  • 機器人狀態：即時顯示運行狀態（導航中 / 閒置）與連線狀況
  • 任務佇列：列出執行中與等待中的任務（含取消按鈕）
  • 系統日誌：顯示最新事件紀錄
  • 通知提示：任務到達取貨點、送達目的地、逾時等事件以彈出訊息通知
4
建立任務
/create-task
 一般使用者
  • 選擇取貨地點（下拉選單）
  • 選擇目的地（下拉選單）
  • 選擇棚架層（僅顯示「使用中」的層；未掛載棚架時停用）
  • 輸入驗證碼（選擇棚架層時為必填，最少 4 碼）
  • 輸入收件人姓名（記錄於任務歷史）
  • 送出任務 / 重設表單
任務送出後立即加入佇列，機器人閒置時自動開始執行
5
任務歷史
/task-history
 一般使用者
  • 依狀態篩選：全部 / 等待中 / 執行中 / 完成 / 已取消 / 失敗
  • 依任務 ID 搜尋
  • 點擊任一列展開詳細資訊：取貨、目的地、收件人、棚架層、各時間點記錄
  • 任務狀態時間軸（Timeline）
  • 「重新執行」按鈕：執行中任務卡住時可重送指令
6
系統日誌
/logs
 一般使用者
  • 篩選機器人（AMR-01 或全部）
  • 關鍵字搜尋
  • 依等級篩選：全部 / INFO / WARNING / ERROR
  • 即時接收新日誌（Socket.io，無需重新整理）
  • 記錄內容：移動指令、連線事件、任務事件、gRPC 錯誤
7
棚架管理
/shelf-management
 一般使用者
  • 查看所有棚架層清單（層號、狀態、最大承重）
  • 狀態：使用中（Active）/ 閒置（Idle）/ 佔用中（Busy）
  • 啟用 / 停用 / 編輯最大承重 / 刪除各層
  • 新增棚架層
僅「使用中」的層會出現在建立任務的選單中
8
系統設定
/settings
 一般使用者
  • 機器人名稱、最高速度、電量警告門檻
  • 自動返回充電站（開關切換）
  • 取貨超時秒數 / 送達超時秒數
  • 介面語言切換（English / 繁體中文）
管理員專屬頁面
9
機器人狀態
/robot-status
 管理員
  • 即時監控：運行狀態、電量 %、速度（m/s）、X / Y 座標、目前任務、連線狀態
  • 手動控制（每個按鈕需二次確認）：
  • 　⏸ 暫停 — 暫停機器人移動
  • 　▶ 繼續 — 從暫停狀態恢復
  • 　📦 掛載棚架 — 機器人抬起棚架
  • 　↑ 卸載棚架 — 機器人放下棚架
  • 　🏠 返回充電站
  • 　🚨 緊急停止 — 立即停止所有動作
任務執行中，僅允許暫停 / 繼續 / 緊急停止；手動移動指令自動封鎖
10
使用者管理
/users
 管理員
  • 建立新帳戶（帳號 + 密碼）
  • 查看所有使用者清單（帳號、建立日期）
  • 刪除一般使用者帳戶（管理員帳戶無法刪除）
11
攝影機
/camera
 管理員
  • 切換鏡頭：前鏡頭 / 後鏡頭 / ToF 深度鏡頭
  • 即時影像串流（約 10 fps）
  • 串流載入中顯示轉圈動畫
  • 串流失敗時顯示「重試」按鈕
